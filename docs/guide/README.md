# Guide

This section lives in `docs/guide/`. Because it has a `README.md`, the folder
becomes a **section** in the nav with its own landing page at `/guide/`.

## How sections work

Drop a folder under `docs/` and every Markdown file or notebook inside becomes a
nested nav item. Add a `README.md` to give the section a landing page and a title; without
one, the folder still appears as a plain group label.
